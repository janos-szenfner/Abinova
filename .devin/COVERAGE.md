## The countable denominator

Counted: every first-party C/C++ source under `src/` that this
Linux build compiles — `af/` (app framework), `text/` (piece
table and layout) and `wp/` (importers/exporters, application
layer, entry points) — including compiled inline/template code
attributed to headers.

Excluded via lcov filters (tools/coverage-excludes.txt):

- `/usr/*` — system headers and libraries — not our code
- `*/thirdparty/*` — vendored libraries (see thirdparty/VENDORED.json)
- `*/fuzz-build/*` — instrumented fuzz/sanitizer scratch tree
- `*/xp/t/*` — autotest sources (test drivers are not product code)
- `*/gtk/t/*` — autotest sources (test drivers are not product code)
- `*/wp/test/*` — autotest sources (test drivers are not product code)
- `*/af/tf/*` — test-harness support library (autotest tooling)
- `*/abi-resources.c` — generated (glib-compile-resources output)
- `*.gperf` — generated (gperf hash emitted as an #include)

Excluded by construction: code that never compiles in this
build contributes no lines to the denominator — `#ifdef
G_OS_WIN32`/`__APPLE__`/other-OS branches and whole files the
build skips.  There is no way to count them short of building
on those platforms; treat their absence as a documented
limitation, not hidden uncovered code.

Counted but flagged: `src/wp/main/gtk` (process entry points)
shows as its own row.
