Wymagania systemowe AbiWorda

Poniżej podajemy wymagania systemu, które jak się nam wydaje pozwolą użytkownikowi w miarę sensownie uruchomić AbiWorda. Są to wymagania szacunkowe -- możliwe, iż nawet na sprzęcie niższej klasy niż to podaliśmy praca będzie komfortowa, możliwe, iż na sprzęcie lepszej klasy praca będzie niezadowalająca. Jak zawsze, wymagania mogą być różne. Chcemy przez to powiedzieć, iż mamy nadzieję, że poniższe dane będą użyteczne.

Microsoft Windows:

  • procesor 486dx lub lepszy
  • co najmniej 16MB pamięci RAM
  • system operacyjny Windows 95b lub późniejszy

GNU/Linux, BSD, Solaris (7,8,9), AIX, HP/UX (10.20, 11.0):

  • zainstalowana biblioteka GTK+ 1.2.x (1.2.10 zalecana)
  • co najmniej 16MB pamięci RAM
  • procesor PPC, Intel (zalecany Pentium lub lepszy), Sparc (zalecany UltraSparc), procesor RISC lub MIPS
  • Opcjonalnie środowisko GNOME 1.4 (GAL >= 0.7, GNOME-Print >= 0.3.0)

Mac OS X:

  • zainstalowane: XDarwin + menedżer okien (zalecany OrcoberOSX)
  • co najmniej 16MB pamięci RAM
  • procesor G3 lub lepszy
  • system operacyjny Mac OS X (zalecany 10.1.2 lub późniejszy)

QNX:

  • procesor klasy Pentium lub lepszy
  • co najmniej 16MB pamięci RAM

BeOS:

  • procesor klasy Intel Pentium lub lepszy, albo PPC G3 lub lepszy
  • co najmniej 16MB pamięci RAM
