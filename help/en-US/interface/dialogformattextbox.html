Format Text Box Dialog

This dialog changes the appearance of your text box. You can set the borders and colors of a selected text box.

Borders: Color

Select the border color. Clicking on the color button next to Color: opens the standard color picker for your operating system. The color of the button indicates the current color of the borders.

When you change a given border setting, such as a border color, you may need to use the border buttons in their corresponding locations (see the diagram on the right side of the dialog) to recreate the border according to the new setting.  Then make the change in your document by clicking Apply as described below.

Background: Color

Select the background. Clicking on the color button next to Color: opens the standard color picker for your operating system. The color of the button indicates the current color of the background.

Preview

Displays an up-to-date preview of how your formatting choices will look in the finished text box.

The four buttons around the edge of the preview set the borders that will be displayed. Click on each button to turn the corresponding border on or off.

Help

This button opens the documentation for this dialog.

Apply

This button applies the current formating choices to the selected dialog. It does not close the dialog.

Close

This button closes the dialog. It does not change the formatting of the text box, but any changes you have applied remain in effect.
