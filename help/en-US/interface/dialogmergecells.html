Merge Cells Dialog

This dialog allows you to merge the cells in a table. It is only available if the insertion point is within a table.

The dialog contains four merge buttons. Every time you press one of these buttons, the current cell is merged with the cell adjacent to it, to create a single large cell within the table. The dialog does not close when the cells merge, so it is possible to merge several cells by pressing the buttons repeatedly.

If a cell spans several columns, as a result of previous merges, and you merge it with the cell above or below, all the cells adjacent to the large cell are merged with it. The same applies to cells spanning several columns.

Merge Left

Merge the current cell with the one to its left.

Merge Right

Merge the current cell with the one to its right.

Merge Above

Merge the current cell with the one above it.

Merge Below

Merge the current cell with the one below it.

Help

This button opens the documentation for this dialog.

Close

This button closes the dialog.
