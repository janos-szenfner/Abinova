Mark Revisions Dialog

The appearance of this dialog changes depending on whether there are already tracked revisions in the document.

Continue previous revision

If the radio button is checked, any changes you make are treated as part of the previous revision. The dialog displays the number of the revision and the associated comment, so that you know what you would be continuing. It is only possible to continue the most recent revision.

This option only appears if there are already tracked revisions in the document.

Start a new revision

If the radio button is clicked, a new revision is started.

This option only appears if there are already tracked revisions in the document.

Comment to be associated with the revision

You can associate a comment with any given revision. This can be a useful aid in remembering why you made specific changes to the document, or, if several people are making revisions, in remembering who made a particular set of revisions.

Help

This button opens the documentation for this dialog.

OK

This button closes the dialog and starts a new revision. There is no visible change until you start typing, but all changes you make after starting a new revision are tracked.

Cancel

This button closes the dialog without creating a new revision.
