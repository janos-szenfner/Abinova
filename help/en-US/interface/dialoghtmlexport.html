HTML Export Options Dialog

This dialog presents you with a set of options for how you want your file exported to HTML. See here for a description of the various options.

Save Settings

This button makes the current settings the default settings for the application.

Restore Settings

This button changes the current settings back to the default settings.

Cancel

This button cancels the export of the file.

OK

This button exports the file with the selected settings.
