Mail Merge Tool

This dialog is a standard Open File dialog. However, instead of looking for Abinova files, it looks for mail merge data source files. When you open a file in this dialog, the information from the mail merge source is inserted in the appropriate mail merge fields in your document.

Cancel

Closes the dialog without performing any action.

OK

Merge the data source with your document
