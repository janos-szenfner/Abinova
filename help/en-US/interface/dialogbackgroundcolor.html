Change Background Color Dialog

This dialog is supplied by your operating system. These instructions apply to Linux.

This dialog allows you to change the background color of the document. The easiest way to do this is to click on the color ring at the left of the dialog to choose the color, and on the triangle to pick how dark or light it is. The rectangle under the wheel shows the new color in its right half.

You can also change the color by changing the values in the boxes to the right of the color ring, or by typing the hexadecimal code for the color in the box. This is useful when you know exactly what color you want to match.

This change is made to the document itself, so that if you print it out the printer will try to color the whole page that shade.

Clear Background Color

This button resets the background color to white. It leaves the dialog open.

Help

Click this button to open the documentation for this dialog.

Cancel

Click this button to close the dialog without changing the background color of the document.

OK

Click this button to change the background color of the document and close the dialog.
