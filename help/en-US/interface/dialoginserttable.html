Insert Table Dialog

Insert a new table into your document.

Table Size

The numbers selected here fix the dimensions of the table you insert. It is possible to insert or delete rows and columns later; see the Table menu.

Number of Columns:

The number of columns you wish this table to have.

Number of Rows:

The number of rows you wish this table to have.

AutoFit Behavior

Automatic column size

This option splits the available width equally amongst all of the columns.

Fixed column width

This option allows you to set a specific width for columns. Change the column size either by typing in the box or clicking on the up and down arrows to its right.

Help

This button opens the documentation for this dialog.

Cancel

This button closes the dialog without inserting a new table.

Insert

This button inserts a new table into the document and closes the dialog.
