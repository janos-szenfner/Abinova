Table Toolbar

This toolbar allows you to work with tables more easily.

This button opens the table widget, which lets you insert a table of any size into your document. Drag on the widget to select the number of rows and columns that you want, and click to insert the table. The number of rows and columns in the table is displayed at the bottom of the widget.

This button inserts a row below the current row.

This button inserts a column to the left of the current column.

This button deletes the current row.

This button deletes the current column.

This button opens the Merge Cells dialog.
