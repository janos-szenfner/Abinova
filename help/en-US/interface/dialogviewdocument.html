View Document Dialog

This dialog allows you to choose to view one of the open documents. Normally you can simply select one from the Window Menu, but if there are too many open documents you should use this dialog to view documents no longer listed in the menu.

Available Documents

This is a list of all the documents that are currently open in AbiWord. Click on one to select it.

Cancel

Close the dialog without changing the active window.

View

Click this button to bring the selected document to the front.
