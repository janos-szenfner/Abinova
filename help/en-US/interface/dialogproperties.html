Document Properties Dialog

This dialog allows you to view and edit your document's metadata. Metadata is information about the document, such as the author's name, or a summary of the subject.

You can enter as much text as you like in each field. You should remember that the metadata is visible to anyone who has access to the document, so if you need to remove confidential information from a document remember to check the metadata as well.

The dialog has three panes: General, Summary, and Permissions. To bring a pane to the front, click on its name. To edit a property, click within the box. Pressing tab will usually move you to the next box as well. The exception is the Description box on the Summary pane, in which pressing tab inserts a tab.

The names of the fields are self-explanatory.

Help

This button opens the documentation for this dialog.

Cancel

Click this button to close the dialog without saving any changes you made to the metadata. If you only wanted to view the metadata, click this button to close, in case you accidentally made any changes.

OK

This button changes the metadata in the document and closes the dialog.
