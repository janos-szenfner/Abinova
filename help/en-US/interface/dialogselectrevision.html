Select Revisions Dialog

Existing revisions:

This window lists all the tracked revisions in the current document. Highlight a revision in the list to select it.

Revision ID

The numeric identifier associated with the revisions.

Comment

The comment associated with the revisions. This is the comment assigned to the revision when it was created in the Mark Revisions dialog.

Help

This button opens the documentation for this dialog.

Cancel

This button closes the dialog without selecting any revisions.

OK

This button closes the dialog and selects the revision highlighted in the list.
