Language Dialog

This dialog lets you tell Abinova the language in which you are writing. This changes the dictionary used for spell-checking, and other properties which depend on the language.

Available Languages

This menu lists all the languages that Abinova knows about. Click on one to select it. If your language is not listed here, then your version of Abinova does not know about your language. Check the Abinova website to see if support has been added since your version was produced.

If you select 'no proofing', Abinova will not try to spell check your document. If your language is not available, this is the best option. 'no proofing' is the first item in the menu.

Help

This button opens the documentation for this dialog.

Cancel

This button closes the dialog without changing the current language.

Set Language

This button sets the current language and closes the dialog.
