Abinova Help: Workspace

The Abinova Workspace

Abinova looks quite similar to other word processors, hopefully making anyone new to the software quite at home.

The familiar interface should allow most people to start working immediately. However, there are some pieces that may be new.

Title Window

The title window itself is like any other application’s window, with one difference. Note the * near “Untitled10“. The star means that “Untitled10“ has been modified. This provides an easy way to tell if the document needs to be saved.

The Ribbon

Abinova uses a ribbon interface inspired by LibreOffice Writer's NotebookBar. Across the top of the window a row of tabs — File, Home, Insert, References, Layout, Review, View, Help — groups every command by task. Home is selected by default and holds the everyday clipboard, font, paragraph and styles controls; browsing the tabs is the best way to get a sense of all that Abinova can do with documents.

Contextual tabs appear only when they are relevant: Table Layout shows up while the caret is inside a table, and the Equation tab while it is on a formula. When the caret leaves, the tab disappears and focus returns to Home. The classic menu bar and toolbars have been removed — the ribbon is the only interface.

Status Bar

The Status Bar allows for a quick over view of the document’s status. On the left, Abinova notes the current page. The middle box, which is usually empty, displays a quick help message describing the current menu option.

The Rulers

By using the rulers it becomes easy to set page margins and tabstops.
