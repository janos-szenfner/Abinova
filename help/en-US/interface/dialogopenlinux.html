Open File

At the top is the path of the current directory that AbiWord is looking for your document in. Clicking it will drop down a menu allowing you to move back one or more directories

Folders / Files

This shows the current folder and the subfolders and files within it. Here you can move between folders in order to find the file to open.

  • The Folders box lists the sub-folders within the current folder.  Double-clicking ../ will move you back one folder. Under that are sub-folders. Double-clicking <folder>/ will move you forward into that folder. Use the scroll bar on the right of this box to scroll through the list.
  • The Files box lists the files within the current folder. Use the Scrollbar on the right of this box to scroll through the files within that folder.

When you have found the file to open, then click on it to highlight it and then click OK, or you may also simply double-click the file to open it.

Open file as type:

Use this drop-down menu to choose the file type that you are opening.

  • Automatically Detected will show all files within the directory.
  • If you select one of the options in the drop-down menu, AbiWord will assume that the file you try to open is of that type. This can be useful for forcing AbiWord to open HTML files as text files rather than importing them with formatting, or when a file does not have the appropriate extension to its name.

Selection:

This shows the name of the file you have selected to be opened.

  • If you know the path to the file, you can type it in here, including the filename, and hit [ENTER] or click OK to open the file.
  • You may also move between folders to find your file here. Using the Folders box as your guide, type in the first few letters of the listed sub-folder you want to move into, hit [TAB] and you will move into that folder. If more than one folder matches to what you typed in, all the matches will be shown in the Folders box, and adding another letter or two and then [TAB] again will move you into that folder. Typing in ../ then [TAB] will move you back one folder. When you are in the correct folder type in the first few letters of the filename to open, hit [TAB] and that file will appear in the Files box. If more than one filename matches what you typed in, then all the matches will be shown in the Files box and adding another letter or two, then [TAB], will complete the filename. Hit [ENTER], or click OK, to open the file. This is case sensitive, so any capital letters will have to be typed as shown.

Help

This button opens the documentation for this dialog.

Cancel

This button closes the dialog without opening a file.

OK

This button closes the dialog and opens the selected document.

Note

Opening more than one file will cause a new window to open for each new file, this is a feature of AbiWord's design.
