File Menu

New...

Opens the New File dialog, allowing you to create a new file based on a template.

Open...

Opens a dialog box to choose the file to open.

Save

Saves the open document. This option is grayed out if the file has not been altered since its last save.

Save As...

Opens a dialog box to save the open document under a different name, or as a different file type, or both.

Open Copy...

Opens a copy of a saved document as a new, untitled document.  If you choose to save the document, Abinova will prompt you for a new name.

Save Copy...

This works just like "Save As...", except you continue editing the file under the original name.  This is good for saving backups of your document at composition milestones.

Export...

Saves a copy of the current document under a new name, as a new type, or both. The open window is the original document, not the copy you have just saved. This differs from Save As. When you Save As, further changes are made to the document you have just saved.

For example, if I have edited foo.abw, and save a copy as foo2.doc, the open document is still foo.abw. If I make further changes and then just save, the changes are saved to foo.abw.

Revert

Undoes all changes made since the document was last saved. They can be Redone by using Redo (on the Edit menu), or the Redo button on the toolbar.

Recent Files

The Recent Files submenu provides shortcuts to the files you have most recently used within Abinova. Selecting a file on this submenu opens that file.

Properties...

Opens the Properties dialog, which allows you to view and edit document metadata -- information about the document, such as the author's name.

Page Setup...

Opens a dialog box to setup the Paper size, Orientation, Scale and Margins.

Print...

Opens a dialog box to print the open document.

Close

If you have more than one Abinova document open, this command closes the current document and its window.

If the current document is the only open Abinova document, this command the document and replaces it with a new, blank document.

Exit

Closes all open documents and exits Abinova
