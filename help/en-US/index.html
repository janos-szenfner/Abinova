Abinova

Abinova is a free word processor built on GTK4. It reads and writes the document formats you actually exchange with other people — Office Open XML, OpenDocument, EPUB, Markdown, LaTeX — without needing any plugin to be installed, and keeps its own compact .abw format (with an encrypted variant) for everyday work.

This project is experimental and supplied without any warranty. See the Changelog (Help ribbon) for what changed in each version.

Documents and file formats

Native format — .abw (AbiWord XML) is the default. .abwn is the same document inside an encrypted envelope; pick a password when saving and the file cannot be opened without it. Encryption is PBKDF2-HMAC-SHA-256 key derivation (600,000 rounds) plus AES-256-GCM, so both the content and the header are authenticated.

Office formats — DOCX / DOTX / DOCM and legacy DOC open and save natively; the code lives in the core, not in a plugin. Complex Word files (tables, fields, comments, tracked changes) are imported to the closest matching document model.

OpenDocument — ODT / OTT and flat-XML FODT open and save with ODF 1.4 declarations. ODF password protection works in both directions: you are asked for the password when opening an encrypted file, and the ODF save dialog offers "Encrypt with password".

EPUB — import an ebook as an editable document, or export the current document as EPUB 3.3 with export options for splitting, metadata and cover handling.

Markdown — .md/.markdown files import and export: headings, emphasis, links, images, nested and task lists, blockquotes, fenced code, pipe tables and hard breaks. YAML frontmatter becomes document metadata, [^id] footnotes become real footnotes, and fenced mermaid blocks are rendered inline as images (flowcharts, sequence, Gantt, class and pie diagrams).

LaTeX — .tex files import (sectioning, formatting, lists, tables, graphics, footnotes, math) and export, so documents can round-trip to and from TeX sources.

Other formats — RTF, HTML, plain text (with encoding detection) and WordPerfect/works documents are supported for import or export as indicated by the file dialog.

Editing and formatting

Styles — paragraph and character styles (Normal, Heading 1-3, lists, etc.) are applied from the Home ribbon or the style box. Direct formatting stacks on top of the style; Ctrl+Space removes character formatting and Ctrl+Q removes direct paragraph formatting while keeping the style.

Formatting — bold, italic, underline, strikethrough, sub/superscript, font family and size, text color and highlight, alignment (left/center/right/justify), line spacing (1, 1.5, 2), paragraph spacing and indentation, bullets and numbering, columns, tab stops, borders and shading — all from the ribbon.

Insertions — page and column breaks, line breaks, tables, images, equations (MathML and LaTeX source), headers and footers, footnotes and endnotes, page numbers and other fields, hyperlinks, comments, symbols and special characters, text boxes and bookmarks.

Find & replace — Ctrl+F / Ctrl+H, with whole-word and match-case options; F3 finds again. Ctrl+G opens Go To.

Tables

Tables have two contextual ribbon tabs that appear when the caret or selection touches a table:

  • Table Design — a Word-compatible style gallery with the Grid Table, List Table and Plain Table families, first/last column and banded row/column options, live preview on hover, and a Clear command that strips all style-owned formatting.
  • Table Layout — insert/delete rows, columns and cells, merge and split cells, cell alignment, auto-fit, borders, shading and table properties.

Tab moves to the next cell (a new row is appended at the end), Shift+Tab moves back, and Ctrl+Alt+arrow keys resize columns and rows from the keyboard.

Review

  • Spell checking — on-the-fly underlining plus the full dialog (F7 or Cmd+;). Dictionaries come from the system enchant providers.
  • Grammar checking — built-in Hunspell-based grammar checking runs in the background and can be toggled in the preferences.
  • Track changes — Ctrl+Shift+E toggles revision marks; insertions, deletions and formatting changes are recorded and shown inline.
  • Comments — Ctrl+Alt+M inserts a comment at the caret; Alt+↑ / Alt+↓ move between comments.

Interface

Ribbon — a LibreOffice/Word-style NotebookBar replaces the old menu bar: File, Home, Insert, References, Layout, Review, View and Help, with contextual tabs for tables and equations. A menu-bar / classic mode is still available from the View options.

Layout views — Print Layout (Ctrl+Alt+P) and Normal/draft (Ctrl+Alt+N), rulers, zoom, split view (Ctrl+Alt+S, remove with Alt+Shift+C) and fullscreen (F11).

Multiple documents — Ctrl+F6 / Ctrl+Shift+F6 cycle through open windows; the Window menu lists them all and can arrange them.

Keyboard shortcuts

The default keymap follows MS Word on every platform. On macOS the Command (⌘) key acts as Control, so Cmd+S, Cmd+B, Cmd+Shift+Z (redo) etc. work as expected; ⌥ is Alt (Option+←/→ move by word, Option+Delete deletes the word before the caret). Highlights:

  • File — Ctrl+N new, Ctrl+O open, Ctrl+S save, F12 / Ctrl+Shift+S Save As, Ctrl+P print, Ctrl+F2 print preview, Ctrl+W close.
  • Editing — Ctrl+Z/Y undo/redo, Ctrl+X/C/V cut/copy/paste, Ctrl+Alt+V paste special, Ctrl+Shift+V paste formatting, Ctrl+A select all, Ctrl+F find, Ctrl+H replace, Ctrl+G go to.
  • Format — Ctrl+B/I/U, Ctrl+Shift+X strike, Ctrl+= sub, Ctrl+Shift+= super, Ctrl+L/E/R/J align, Ctrl+1/5/2 spacing, Ctrl+0 space before, Ctrl+M / Ctrl+Shift+M indent, Ctrl+Q clear paragraph formatting, Ctrl+Space clear character formatting, Ctrl+Shift+N Normal, Alt+Ctrl+1/2/3 headings.
  • Insert — Ctrl+Enter page break, Shift+Enter line break, Ctrl+Shift+Space non-breaking space, Ctrl+K hyperlink, Ctrl+Alt+F footnote, Ctrl+Alt+D endnote, Ctrl+Alt+M comment, Ctrl+Alt+C/R/T for ©/®/™, Ctrl+Alt+- em dash, Ctrl+- soft hyphen, Ctrl+Shift+- non-breaking hyphen.

The full table is in the README. Emacs and vi keymaps are still available through the input-mode switcher.

Safety

Abinova autosaves recovery copies in the background; after a crash the next start offers to restore them. Recovery copies of password-protected documents stay encrypted. Documents are written atomically via a sibling .part file so a failed save never destroys the existing file.
