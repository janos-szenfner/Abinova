Built-in Features

Abinova no longer uses plug-ins. Everything that used to ship as an optional loadable module is now compiled into the application itself, so there is nothing extra to install or enable.

The following features, formerly plug-ins, are always available:

  • OpenDocument Text (.odt) — open, edit, save and save-as, including flat-XML (.fodt) files, password-protected documents and RDF metadata.
  • Office Open XML (.docx) — open, edit, save and save-as Word 2007+ documents.
  • EPUB — import and export EPUB 3 e-books (EPUB 2 also supported).
  • Grammar checking — sentence-level checking powered by Hunspell, toggled in the spelling preferences.
  • Microsoft Word 97-2003 (.doc) — legacy Word documents via the bundled wv library.
  • WordPerfect (.wpd) and MS Works documents.
  • Markdown (.md) and LaTeX (.tex) — full import and export.
  • MHTML (.mht/.mhtml), WMF images and WPG graphics.

There is no plug-in manager and nothing to install — every feature listed above is always part of Abinova.
